# Python 学习记忆与进度交接文档

## 1. 【已掌握清单】

### 1.1 基础语法、数据类型与输入输出（Exercise 0 – Exercise 12）
* **基础输出**：`print()` 函数用法；通过 `end=" "` 控制 `print()` 输出不换行（对应 Python 2 末尾加逗号 `,`）。
* **注释机制**：使用 `#` 添加单行或行尾注释，以及通过 `#` 暂时屏蔽代码（`comment out`）；理解字符串引号内部的 `#` 仅作为普通字符。
* **核心数据类型**：整数 `int`、浮点数 `float`、字符串 `str`、布尔值 `bool`（`True` 与 `False`，首字母大写且不加引号）。
* **数学与比较运算符**：
  * 算术运算：`+`（加）、`-`（减）、`*`（乘）、`/`（Python 3 浮点除法）、`//`（整除）、`%`（求余/模运算）及优先级顺序；
  * 增量赋值：`+=`、`-=` 等缩写运算符；
  * 比较运算：`<`、`>`、`<=`、`>=`、`==`（相等判断）、`!=`（不等于）。
* **变量与命名**：变量赋值 `=` 的“先算右边、再存左边”执行顺序；`snake_case`（下划线命名法）及大小写敏感规则。
* **字符串操作与格式化**：
  * 字符串拼接（`+`）与字符串重复（`*`）；
  * 旧式 `%` 格式化：`%s`（日常字符串显示）、`%d`（整数显示）、`%r`（内部原始表示 `representation`，自带引号，用于调试）以及多变量元组传入 `"%s %d" % (a, b)`；
  * 现代 `f-string` 格式化：`f"Hello {name}"`；
  * 四舍五入函数 `round()`。
* **多行字符串与转义序列（`escape sequences`）**：三引号 `"""..."""` 与 `'''...'''`；常用转义符 `\n`（换行）、`\t`（制表缩进）、`\\`（反斜杠）、`\"` 与 `\'`（引号转义）。
* **用户输入与文档查看**：`input("prompt ")`（对应 Python 2 的 `raw_input()`）；使用 `int()` 和 `float()` 进行类型转换；使用 `help()` 查看函数帮助文档。

### 1.2 模块导入与命令行参数（Exercise 13 – Exercise 14）
* **模块（`module`）与导入（`import`）**：使用 `from sys import argv` 从标准库 `sys` 模块中导入命令行参数变量 `argv`。
* **命令行参数与解包（`unpacking`）**：理解 `argv` 保存程序启动时传入的所有参数（首元素固定为脚本文件名 `.py`，其余元素均为字符串）；掌握按位置一一对应的序列解包语法（如 `script, first, second, third = argv`）。
* **交互式提示设计**：将重复使用的提示符保存到变量（如 `prompt = "> "`），结合启动传参 `argv` 与运行期交互 `input(prompt)` 构建完整交互程序。

### 1.3 文件读写操作 File I/O（Exercise 15 – Exercise 17）
* **避免硬编码（`hard-coding`）**：通过参数或用户输入动态指定文件名，而非在代码中写死。
* **文件打开与模式（`mode`）**：`open(filename, mode)`，掌握默认只读模式 `'r'`、写入模式 `'w'`（打开即自动清空原文件或新建文件）、追加模式 `'a'` 及读写模式 `'r+'`。
* **文件对象（`file object`）与点号方法（`method`）**：
  * `f.read()`：读取全部文件内容为字符串；
  * `f.readline()`：逐行读取内容（含行末 `\n`）并推进读写指针（磁头）；
  * `f.write(str)`：向文件写入字符串；
  * `f.truncate()`：清空文件内容；
  * `f.seek(0)`：将文件读写指针（磁头）移回文件开头第 0 字节；
  * `f.close()`：保存并关闭文件释放资源。
* **文件系统辅助工具**：`from os.path import exists`（检查文件是否存在，返回 `True`/`False`）；内置函数 `len()`（测量字符串/文件字节长度）。

### 1.4 函数与返回值 Functions（Exercise 18 – Exercise 21, Exercise 24）
* **函数定义与调用**：`def 函数名(参数):` 语法、末尾冒号 `:` 以及 **4 空格缩进（`indentation`）**与取消缩进（`dedent`）的代码块边界规则；区分“定义函数（define）”与“调用函数（call/run）”的执行时机。
* **参数传递机制**：位置参数、可变参数打包 `*args` 与解包；函数局部变量作用域（内外变量相互独立）；传参的 4 种形式（直接传值、传变量、传数学表达式、变量与运算组合）。
* **函数与文件结合**：将 `file object` 作为参数传入函数进行读取、倒带与逐行打印。
* **返回值（`return`）与嵌套调用**：使用 `return` 返回单个结果或多个结果（打包为 `tuple` 并配合解包接收）；理解多层嵌套函数调用“由内向外（Inside-out）”的执行顺序。

### 1.5 字符串与列表处理、编解码基础（Exercise 22 – Exercise 26）
* **文本切分与列表操作方法**：
  * `str.split(' ')`：按空格将字符串切分为单词列表 `list`；
  * `sorted(list)`：按 ASCII / 字母顺序返回排好序的新列表；
  * `list.pop(0)` 与 `list.pop(-1)`：弹出（获取并从原列表删除）首元素或末元素；
  * 函数文档字符串 `docstring`（函数首行 `"""..."""` 说明）。
* **新版第 5 版补充概念**：字符串与字节转换 `.encode("utf-8")` 与 `.decode("utf-8")`；列表 `list` 的 0 基索引取值（`items[0]`）；字典 `dict` 的花括号键值对定义与键名取值（`data["key"]`）。

### 1.6 布尔逻辑与条件分支（Exercise 27 – Exercise 31 / 新版 Exercise 28 – Exercise 32）
* **布尔逻辑运算符**：`and`（与/并且）、`or`（或/或者）、`not`（非/取反）；真值表规律、复杂布尔表达式的“剥洋葱”分步化简法，以及短路求值（`short-circuit evaluation`）与 `and`/`or` 返回操作数原值的机制。
* **条件分支结构**：`if`、`elif`（else if）、`else` 多路互斥分支结构（与多个独立 `if` 语句的执行差异）；嵌套 `if` 语句（Nested `if`，4 空格与 8 空格多层缩进）及结合 `input()` 的交互式分支决策。

### 1.7 已接触的标准库
* `sys`（`sys.argv`）
* `os.path`（`os.path.exists`）

## 3. 【个人薄弱点与易错习惯】

1. **输入数据默认类型盲区（`str` vs `int`/`float`）**：
   * `input()` 和 `sys.argv` 获取的所有数据默认都是字符串 `str`。在条件判断中容易写成 `if door == 1:`（字符串 `"1"` 与整数 `1` 比较永远为 `False`），必须写成 `if door == "1":`；在做数值相加或比较大小前，容易忘记先用 `int()` 或 `float()` 转换类型，导致字符串拼接（如 `"10" + "20"` 得到 `"1020"`）或 `TypeError`。
2. **Python 2 课件与 Python 3 运行环境的语法差异**：
   * 老师课件中出现的 `print "..."`（无括号）、`raw_input()`、`print ...,`（末尾逗号不换行）在 Python 3 中会直接触发 `SyntaxError` 或 `NameError`；
   * 除法运算符 `/` 在 Python 3 中永远返回 `float`（如 `100 / 2` 得到 `50.0`），与老师旧版教材印出的整数结果（`50`）不同，属于版本机制差异而非代码错误。
3. **赋值 `=` 与相等比较 `==` 混淆，以及冒号/缩进错误**：
   * 在 `if` 或 `elif` 条件中容易把 `==` 误写成 `=`，触发 `SyntaxError`；
   * 在 `def`、`if`、`elif`、`else` 行末尾容易漏写英文冒号 `:`，或下一行缩进不一致（嵌套分支需严格保持 4 空格与 8 空格层级），触发 `IndentationError`；
   * 容易误在 `else:` 后面写条件表达式（`else:` 后只能直接跟冒号）。
4. **布尔条件表达式简写陷阱与分支逻辑混淆**：
   * 受口语习惯影响，容易将多条件判断误写为 `if choice == "1" or "2":`（因非空字符串 `"2"` 恒为真，导致该条件永远成立），必须完整写成 `if choice == "1" or choice == "2":`；
   * 需注意 `if - elif - else`（多选一互斥，一旦某分支为 `True` 便跳过后续所有分支）与多个独立 `if`（从上到下逐一检查）的区别。
5. **函数 `print()` 与 `return` 职责混淆**：
   * 容易误以为函数内部使用 `print()` 输出结果后，外部就能用 `=` 接住该值；若函数内不写 `return`，外部变量接收到的只会是 `None`。同时在多层嵌套函数调用中，需牢记执行顺序是**由内向外（Inside-out）**逐层求值。
6. **文件操作（File I/O）常见误区**：
   * 误以为 `txt = open(filename)` 返回的是文本内容（实际返回的是 `file object`，必须调用 `txt.read()` 才能读取文本，且不能漏掉括号写成 `txt.read`）；
   * 写入文件时忘记在 `open(filename, 'w')` 中传入 `'w'` 模式（默认 `'r'` 只读模式下调用 `.write()` 或 `.truncate()` 会报 `io.UnsupportedOperation`）；
   * 误以为 `target.write()` 会自动换行（必须手动写入 `"\n"`），且 `.write()` 只能接收 1 个字符串参数；
   * 调用 `f.read()` 读完全文后，读写指针已停在文件末尾，若不先执行 `f.seek(0)` 倒带就直接调用 `f.readline()`，只会读出空字符串 `""`；操作结束后需调用 `.close()`。
7. **新旧教材题号错位**：
   * 自 Exercise 22 起，新版第 5 版教材题号与老师旧版教材不再一致（旧版 Ex 27–33 对应新版 Ex 28–34；旧版 Ex 38–44 对应新版 Ex 42–48），对照看书与提交作业时需核对章节标题与题号映射。

## 4. 【偏好教学风格】

1. **讲解深度与颗粒度（越详细越好，拒绝简略）**：
   * 处于系统打基础阶段，不喜欢高度浓缩或一笔带过的总结。每个 Exercise 都需要详细拆解，确保真正理解底层执行机制，而不是单纯做代码翻译。
2. **标准章节讲解结构**：
   * 每当教授新的 Exercise 时，优先按以下清晰结构展开：
     1. **新增知识点清单**：明确指出本节相比前面章节新增了哪些语法或概念；
     2. **概念与原理解析**：用通俗具体的类比（如 DVD 播放机/磁带机磁头、剥洋葱化简法）讲透概念本质与语法规则；
     3. **代码逐行执行顺序**：按 Python 实际运行轨迹，逐步追踪变量内部保存的值及控制流跳转过程；
     4. **完整运行输出演示（What You Should See）**：必须完整展示代码运行后的屏幕输出效果（含交互输入过程）；
     5. **常见错误（Common Errors）及原因**：列出本节最容易触发的具体报错类型（如 `SyntaxError`、`NameError`、`TypeError`、`ValueError`、`IndentationError`、`FileNotFoundError`）及排错原因；
     6. **新旧教材对比**：当老师旧版 Python 2 教材与新版 Python 3 教材存在写法或输出差异（如 `%r` 带引号 vs `f-string` 不带引号、除法小数位、题号错位）时，明确指出差异点。
3. **语言与术语规范**：
   * 全程以**中文**讲解为主，同时**保留关键英文编程术语**（如 `variable`、`string`、`input`、`argument`、`unpacking`、`module`、`file object`、`hard-coding`、`indentation`、`return`、`docstring`、`short-circuit evaluation` 等）。
4. **代码输出与作业互动规则**：
   * **可运行性**：所有示例代码和作业代码必须能在 **Python 3** 环境下直接运行。
   * **无批注原则（极其重要）**：当提供可直接复制运行的代码或完成指定 Exercise 的最终代码时，**严禁在代码中添加任何解释性注释（`# ...`），除非主动要求**。
   * **分步互动节奏**：如果仅询问某个 Exercise 有什么新知识，先详细讲解新增知识与原理，不要直接把整份作业做完；当明确要求“把某个 Exercise 做好给我”或“继续向下教”时，再按上述详细标准推进。
